> 这是一篇写作结构示例，不代表已经完成的项目。

## 先描述问题

写清楚项目的目标、输入和预期输出。范围越明确，越容易判断是否完成。

## 记录关键尝试

一段代码、一个报错或一张结果图，都可以成为笔记的起点。例如，用一个简单函数整理实验结果：

```python
def average(values):
    if not values:
        raise ValueError("数据不能为空")
    return sum(values) / len(values)

print(average([2, 4, 6]))  # 4.0
```

写代码之外，也写下为什么做出这个选择，以及它的适用条件。

## 最后做一次复盘

- 哪些方法有效？
- 遇到了什么问题，如何定位？
- 下一次可以怎样改进？

把源代码放在 GitHub，把过程留在博客，两者互相补充。
